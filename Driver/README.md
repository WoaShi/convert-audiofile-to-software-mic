# 虚拟音频驱动集成说明

## 版权与授权声明
本项目严格遵守第三方软件许可协议：
- 本项目开源仓库与安装包中**不内置、不捆绑任何第三方受版权保护的商业驱动二进制文件**。
- 软件提供官网直达入口，由用户前往官方站点自行下载官方正版驱动：[VB-Audio CABLE](https://vb-audio.com/Cable/index.htm)。

## 驱动特性
- **微软官方 WHQL 认证**：通过微软硬件商业认证，在正式版 Windows 10/11 中无需开启测试模式，无需重启。
- **直通管道链路**：`CABLE Input -> CABLE Output` 或 `VoiceMeeter Input -> VoiceMeeter Output`。
